# HexGTM

This repository is created to train the Graph Tsetlin Machine to predict the winner of a Hex game at three points: at the end of the game, two moves before the end, and five moves before the end. The last two ask for the winner of a game that is not finished yet.

▶ See this project in the film *Show Its Work*: https://youtu.be/pefnyZ-oCcM?t=140

## Status

Right now the repository contains only this README. There is no code, data or results here, so there is nothing to install or run.
